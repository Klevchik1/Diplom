📋 ОПИСАНИЕ ПРОЕКТА
Название: Кинотеатр Премьера (Cinema Management System)

Назначение: Веб-приложение для управления кинотеатром с возможностью бронирования билетов, управления фильмами/залами/сеансами, генерации отчётов, обработки платежей через YooKassa и импорта фильмов из API Poiskkino.dev.

Стек технологий:

База данных	PostgreSQL
Платежи	YooKassa API (yookassa==3.10.1)

SMTP	Яндекс.Почта
PDF генерация	ReportLab 4.4.10
QR-коды	qrcode 8.2 + pillow 12.1.1
Веб-сервер	Gunicorn + Nginx
Процесс-менеджер	Supervisor
CI/CD	GitHub Actions
Тесты	pytest 8.0.0 + selenium 4.16.0

Генерация данных	Faker 40.8.0

🔧 КЛЮЧЕВЫЕ ФУНКЦИОНАЛЬНОСТИ
Ядро системы
Бронирование мест — выбор мест через интерактивную схему зала (JS + AJAX)

Групповые покупки — TicketGroup с UUID, общая оплата через YooKassa

PDF билеты с QR-кодом — generate_enhanced_ticket_pdf() (DejaVu шрифты)

Расчёт цен — base_price × price_coefficient × time_multiplier → округление до целого

Возврат билетов — ограничение 30 минут до сеанса, возврат всей группы через TicketGroup.request_refund()

YooKassa — создание платежей, чеки (54-ФЗ), возвраты, webhook (/webhook/yookassa/)
