🎬 КИНОТЕАТР — ПОЛНЫЙ ПРОМТ ДЛЯ РАЗРАБОТКИ

📋 ОПИСАНИЕ ПРОЕКТА

Веб-приложение для управления кинотеатром. Стек: Django 5.2 + PostgreSQL + YooKassa + Poiskkino.dev API. Приложение позволяет бронировать билеты, управлять фильмами/залами/сеансами, генерировать отчёты, обрабатывать платежи.

📊 МОДЕЛИ ДАННЫХ (19+)

Пользователи и аутентификация:

User (AbstractUser): email как USERNAME_FIELD, is_email_verified, коды подтверждения
PendingRegistration: временные данные до подтверждения email (30 мин)
PasswordResetRequest: 6-значные коды сброса (30 мин)
EmailChangeRequest: смена email с подтверждением

Кинотеатральная логика:

Country, HallType, Hall, Genre, AgeRating
Director, Actor (связи ManyToMany через MovieDirector, MovieActor)
Movie (связи с жанром, рейтингом, режиссёрами, актёрами)
Screening (авторасчёт end_time, расчёт цены по времени суток и типу зала)
Seat (места в залах, создаются автоматически при создании Hall)

Билеты и платежи:

TicketStatus (коды: active, refunded и др.)
TicketGroup (группировка билетов одной покупки, UUID)
Ticket (QR-код, возврат, проверка 30 мин до сеанса)
Payment (YooKassa: payment_id, статусы, возвраты)
BackupManager (восстановление БД с отслеживанием статуса)

Системные модели:

ActionType (CREATE, UPDATE, DELETE, VIEW, EXPORT, LOGIN, BACKUP, REPORT...)
ModuleType (USERS, MOVIES, HALLS, SCREENINGS, TICKETS, REPORTS, BACKUPS...)
OperationLog (логирование всех операций + JSONField)
Report (модель-заглушка для отчётов в админке)

🔧 КЛЮЧЕВЫЕ ФУНКЦИОНАЛЬНОСТИ
Ядро:

Бронирование с выбором мест через JSON
Групповые покупки (TicketGroup с UUID, YooKassa)
PDF билетов с QR-кодом (DejaVu шрифты)
Расчёт цен: base_price × price_coefficient × time_multiplier → округление до целого
Возврат билетов/групп (ограничение 30 мин до сеанса)
YooKassa: платежи, чеки (54-ФЗ), возвраты, webhook

Ролевой доступ:

Обычные пользователи (клиенты)
Менеджеры (is_staff или группа Manager) — /manager/*
Администраторы (is_superuser) — /admin/*
ManagerAccessMiddleware — проверка доступа

Безопасность:

Аутентификация только по email
Двухэтапная верификация email (6 цифр, 10 мин)
Восстановление пароля (6 цифр, 30 мин)
Смена email с подтверждением

Администрирование:

LoggingModelAdmin — автоматическое логирование CRUD
Отчёты: revenue, популярность фильмов, загруженность залов, продажи
Бэкапы: полные/ежедневные, восстановление с логированием
Экспорт логов в CSV/JSON/PDF
Импорт фильмов из Poiskkino.dev API
