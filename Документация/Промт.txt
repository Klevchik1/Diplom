📊 МОДЕЛИ ДАННЫХ (19+ МОДЕЛЕЙ)

👤 ПОЛЬЗОВАТЕЛИ И АУТЕНТИФИКАЦИЯ:

User (AbstractUser, кастомный менеджер CustomUserManager)

Поля: email (уникальный, USERNAME_FIELD), name, surname, number
is_email_verified, email_verification_code, email_verification_code_sent_at
created_at, updated_at
Методы: generate_email_verification_code(), is_verification_code_expired(), verify_email(), requires_email_verification()
Кастомный save() с проверкой уникальности email и логированием

PendingRegistration — временные данные регистрации

Поля: email, name, surname, number, password (хэш), verification_code, created_at
Методы: is_expired() (30 минут), create_user()

PasswordResetRequest — запросы сброса пароля

Поля: user (FK), reset_code, created_at, expires_at (30 мин), is_used
Методы: is_expired(), mark_as_used()

EmailChangeRequest — запросы смены email

Поля: user (FK), new_email, verification_code, created_at, expires_at, is_used
Аналогично PasswordResetRequest

🎬 КИНОТЕАТРАЛЬНАЯ ЛОГИКА:
Country — Страны (name, code — уникальный 2-символьный)

HallType — Типы залов (name, description, price_coefficient, base_price)

Hall — Кинозал

Поля: name, rows, seats_per_row, description, hall_type (FK), created_at, updated_at
Методы: create_seats(), каскадное delete() (удаляет сеансы → билеты)
Автосоздание мест при save() нового зала + сигнал post_save

Genre — Жанры (name уникальный с автоформатированием Title Case)

AgeRating — Возрастные рейтинги (0+, 6+, 12+, 16+, 18+)

Director — Режиссёры (name, surname, birth_date, country (FK), biography)

Actor — Актёры (аналогично Director)

Movie — Фильм

Поля: title, short_description, description, duration (IntegerField минут), poster, release_year, genre (FK), age_rating (FK)
directors → ManyToMany через MovieDirector ✨
actors → ManyToMany через MovieActor ✨
Методы: get_duration_display() (ЧЧ:ММ), автосоздание short_description из description

MovieDirector — Связка фильм-режиссёр (unique_together)

MovieActor — Связка фильм-актёр (unique_together)

Screening — Сеанс

Поля: movie (FK), hall (FK), start_time, end_time (авторасчёт), ticket_price
Методы: calculate_ticket_price() (учёт HallType + времени суток), get_time_multiplier() (0.7/0.9/1.2/1.4), get_price_calculation_explanation(), get_time_description()
clean(): проверка пересечений, времени работы (8:00-23:00, окончание до 00:30)
Автопересчёт цены при изменении зала/времени

Seat — Место (hall FK, row, number; unique_together: hall, row, number)

TicketStatus — Статусы билетов (code, name, is_active, can_be_refunded)

TicketGroup — Группа билетов ✨

Поля: group_uuid (UUID), user, screening, purchase_date, total_amount, tickets_count
Методы: request_refund() (возврат всей группы с логированием), can_be_refunded()

Ticket — Билет

Поля: user, screening, seat, qr_code, price, status (FK), ticket_group (FK)
refund_requested_at, refund_processed_at
unique_together: ('screening', 'seat')
Методы: can_be_refunded() (проверка 30 мин до сеанса), request_refund() (автовозврат), process_refund() (админ), cancel_refund_request(), get_pdf_url(), get_group_tickets()

🛠️ СИСТЕМНЫЕ МОДЕЛИ:

ActionType — Типы действий (CREATE, UPDATE, DELETE, VIEW, EXPORT, LOGIN, LOGOUT, BACKUP, REPORT, OTHER)

ModuleType — Модули (USERS, MOVIES, HALLS, SCREENINGS, TICKETS, REPORTS, BACKUPS, SYSTEM, AUTH)

OperationLog — Логирование

Поля: user, action_type (FK), module_type (FK), description, ip_address, user_agent, object_id, object_repr, additional_data (JSONField), timestamp

BackupManager — Управление бэкапами

Поля: name, backup_file, backup_type (full/daily), backup_date, restored_at, restoration_status (pending/in_progress/completed/failed), restoration_log, user
Методы: get_file_path(), file_exists(), file_size(), can_be_restored(), restore_database(), get_restoration_color()

Report — Модель-заглушка для отчётов в админке
