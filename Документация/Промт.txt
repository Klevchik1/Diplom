📊 МОДЕЛИ ДАННЫХ (19+ МОДЕЛЕЙ)

👤 ПОЛЬЗОВАТЕЛИ И АУТЕНТИФИКАЦИЯ

User (AbstractUser, кастомный менеджер CustomUserManager)

Поля: email (уникальный, USERNAME_FIELD), name, surname, number
is_email_verified, email_verification_code, email_verification_code_sent_at
created_at, updated_at
Методы: generate_email_verification_code(), is_verification_code_expired(), verify_email(), requires_email_verification()
Кастомный save() с проверкой уникальности email и логированием

PendingRegistration — временные данные регистрации

email, name, surname, number, password (хэш), verification_code, created_at
is_expired() (30 минут), create_user()

PasswordResetRequest — запросы сброса пароля

user (FK), reset_code, created_at, expires_at (30 мин), is_used

EmailChangeRequest — запросы смены email

user (FK), new_email, verification_code, created_at, expires_at, is_used

🎬 КИНОТЕАТРАЛЬНАЯ ЛОГИКА

Country — Страны (name, code — уникальный 2-символьный)

HallType — Типы залов (name, description, price_coefficient, base_price)

Hall — Кинозал (name, rows, seats_per_row, description, hall_type (FK))

create_seats(), каскадное delete() + сигнал post_save

Genre — Жанры (name уникальный с автоформатированием Title Case)

AgeRating — Возрастные рейтинги (0+, 6+, 12+, 16+, 18+)

Director — Режиссёры (name, surname, birth_date, country (FK), biography)

Actor — Актёры (аналогично Director)

Movie — Фильм

title, short_description, description, duration (IntegerField минут), poster, release_year, genre (FK), age_rating (FK)
directors → ManyToMany через MovieDirector
actors → ManyToMany через MovieActor
get_duration_display() (ЧЧ:ММ)

MovieDirector — Связка фильм-режиссёр (unique_together)

MovieActor — Связка фильм-актёр (unique_together)

Screening — Сеанс

movie (FK), hall (FK), start_time, end_time (авторасчёт), ticket_price
calculate_ticket_price() (учёт HallType + времени суток), get_time_multiplier() (0.7/0.9/1.2/1.4)
clean(): проверка пересечений, времени работы (8:00-23:00, окончание до 00:30)

Seat — Место (hall FK, row, number; unique_together)

TicketStatus — Статусы билетов (code, name, is_active, can_be_refunded)

TicketGroup — Группа билетов

group_uuid (UUID), user, screening, purchase_date, total_amount, tickets_count
payment_status (pending_payment/paid/canceled), expires_at
request_refund() (возврат всей группы с YooKassa + логирование), can_be_refunded()

Payment — Платежи YooKassa

ticket_group (OneToOne), payment_id, idempotence_key, status, amount, currency
payment_method, card_last4, card_type, confirmation_url
refund_id, refund_status
is_expired()

Ticket — Билет

user, screening, seat, qr_code, price, status (FK), ticket_group (FK)
refund_requested_at, refund_processed_at
unique_together: ('screening', 'seat')
can_be_refunded() (проверка 30 мин до сеанса), request_refund(), process_refund(), cancel_refund_request()

🛠️ СИСТЕМНЫЕ МОДЕЛИ

ActionType — Типы действий (CREATE, UPDATE, DELETE, VIEW, EXPORT, LOGIN, LOGOUT, BACKUP, REPORT, OTHER)

ModuleType — Модули (USERS, MOVIES, HALLS, SCREENINGS, TICKETS, REPORTS, BACKUPS, SYSTEM, AUTH)

OperationLog — Логирование (user, action_type, module_type, description, ip_address, user_agent, object_id, object_repr, additional_data (JSONField), timestamp)

BackupManager — Управление бэкапами (name, backup_file, backup_type, restoration_status, restore_database())

Report — Модель-заглушка для отчётов в админке
