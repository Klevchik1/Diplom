# 🎬 КИНОТЕАТР «ПРЕМЬЕРА»

**Веб-приложение для автоматизации работы современного кинотеатра**

---

## 📖 О ПРОЕКТЕ

Веб-приложение «Кинотеатр» — это комплексное решение для автоматизации ключевых бизнес-процессов кинотеатра. Система предоставляет пользователям удобный сервис для онлайн-бронирования и покупки билетов, а администрации — инструменты для управления репертуаром, залами, сеансами и анализа продаж.

Разработанное в рамках дипломного проекта, приложение решает проблему очередей в кассы, оптимизирует внутренние операционные процессы и предоставляет руководству кинотеатра аналитику для принятия управленческих решений.

---

## 🎯 ЦЕЛИ И ЗАДАЧИ

| Для кого | Что решает |
|----------|------------|
| **Зрители** | Быстрый и удобный онлайн-сервис для выбора фильмов, бронирования мест и оплаты билетов без посещения кассы |
| **Менеджеры** | Инструменты для управления репертуаром, расписанием сеансов и контроля продаж |
| **Администрация** | Полный контроль над всеми процессами кинотеатра и аналитические отчёты для принятия решений |

---

## ✨ ОСНОВНЫЕ ВОЗМОЖНОСТИ

### Для зрителей

- **Просмотр афиши** — актуальное расписание фильмов с постерами, описаниями, жанрами и возрастными рейтингами
- **Умный поиск и фильтры** — быстрый поиск фильмов по названию, дате, жанру, залу и возрастному рейтингу
- **Интерактивная схема зала** — наглядный выбор свободных мест с отображением занятых
- **Онлайн-оплата** — безопасная оплата билетов через платёжную систему YooKassa
- **Электронные билеты** — PDF-билеты с QR-кодом для прохода в кинозал
- **Личный кабинет** — история покупок, скачивание билетов и возврат онлайн
- **Восстановление пароля** — удобная процедура сброса пароля через email

### Для менеджеров

- **Управление фильмами** — создание, редактирование и удаление фильмов
- **Импорт из API** — автоматический импорт фильмов, актёров, режиссёров и жанров из внешнего API
- **Управление сеансами** — создание расписания с автоматическим расчётом цены билета
- **Статистика продаж** — наглядные отчёты по выручке, популярным фильмам и загруженности залов
- **Управление API-токенами** — контроль доступа к внешним сервисам

### Для администраторов

- **Полное управление данными** — CRUD-операции над всеми сущностями системы
- **Управление пользователями** — просмотр, редактирование, блокировка и удаление
- **Управление ролями** — настройка прав доступа для сотрудников
- **Управление залами** — создание залов с автоматической генерацией схемы мест
- **Логирование операций** — полный аудит всех действий пользователей
- **Экспорт отчётов** — выгрузка статистики в PDF, CSV, JSON и XLSX форматах

| Компонент | Технология |

| **Серверная часть** | Python, Django 5.2 |

| **Среда разработки** | PyCharm Professional |

## 📊 МОДЕЛЬ ДАННЫХ

Система оперирует следующими ключевыми сущностями:

### Пользователи и аутентификация
- **Пользователь** — регистрация по email с двухэтапной верификацией
- **Запрос сброса пароля** — восстановление доступа через 6-значный код
- **Запрос смены email** — смена контактной информации с подтверждением

### Кинотеатральная логика
- **Фильм** — основная кинопродукция с полным описанием, жанрами, странами, режиссёрами и актёрами
- **Возрастной рейтинг** — классификация по возрастным ограничениям
- **Кинозал** — физическое помещение с типом, количеством рядов и мест
- **Место** — конкретное место в зале с координатами
- **Сеанс** — показ фильма в зале в определённое время
- **Группа билетов** — объединение билетов одной покупки с уникальным идентификатором
- **Билет** — электронный документ с QR-кодом и статусом
- **Платёж** — информация о транзакции через YooKassa

### Системные модели
- **Лог операций** — полный аудит действий пользователей
- **Тип действия** — классификация операций (создание, редактирование, удаление и т.д.)
- **Модуль системы** — идентификация компонентов приложения
- **API-токен** — управление ключами доступа к внешним сервисам

## 🔒 БЕЗОПАСНОСТЬ

- **Аутентификация по email** — в качестве логина используется адрес электронной почты
- **Двухэтапная верификация email** — подтверждение через 6-значный код (действует 10 минут)
- **Надёжное хранение паролей** — хэширование с использованием PBKDF2 и SHA-256
- **Защита от распространённых уязвимостей** — CSRF-защита, SQL-инъекции, XSS-атаки
- **Разграничение доступа** — строгая проверка прав на серверной стороне
- **Логирование операций** — полный аудит всех действий пользователей
